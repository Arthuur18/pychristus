Fundamentos de Python

Nesta seção, exploramos os pilares que sustentam a linguagem Python. Você aprenderá como o computador armazena informações e como realizamos operações básicas.

O que são Fundamentos?

Os fundamentos de uma linguagem de programação referem-se às regras básicas de sintaxe, gramática e estrutura que permitem que o código seja interpretado corretamente pela máquina.

Dominar esses conceitos é como aprender o alfabeto antes de escrever um romance: sem entender como Python organiza blocos de código ou lida com notas explicativas, é impossível construir aplicações complexas e escaláveis.

Comentários em Python

Comentários são notas para humanos que o Python ignora. Use # para comentários de uma linha.

Python Shell 
# Isso é um comentário
print("Python é incrível") # Comentário após código
lightbulb

Dica Profissional

Use comentários para explicar o 'porquê' do código, não o 'quê' ele faz. O código deve ser legível por si só.

Indentação

Em Python, o espaço no início da linha é obrigatório para definir blocos de código. Diferente de outras linguagens que usam chaves {}, Python usa o vazio para criar hierarquia.

error

Erro Comum

O erro IndentationError acontece quando você esquece os 4 espaços obrigatórios ou mistura espaços com tabulações.

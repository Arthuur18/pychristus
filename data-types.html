Tipos de Dados em Python

Python é uma linguagem de tipagem dinâmica. Isso significa que você não precisa declarar o tipo de uma variável ao criá-la; o interpretador infere o tipo automaticamente com base no valor atribuído. Conhecer os tipos básicos é fundamental para manipular informações de forma precisa.

123

Inteiros (int)

Números inteiros sem casas decimais, positivos ou negativos.

idade = 25
decimal_increase

Ponto Flutuante

Números decimais. Note que usamos o ponto (.) como separador.

preco = 49.99
text_fields

Strings (str)

Cadeias de caracteres delimitadas por aspas simples ou duplas.

nome = "Python"
toggle_on

Booleanos (bool)

Valores lógicos binários que representam verdadeiro ou falso.

ativo = True

Exemplo Prático

# Definindo diferentes tipos de dados
nome = "Estudante"           # String
idade = 21                    # Integer
altura = 1.75                 # Float
esta_matriculado = True       # Boolean

# Verificando os tipos com a função type()
print(type(nome))              # <class 'str'>
print(type(idade))             # <class 'int'>
print(type(altura))            # <class 'float'>
print(type(esta_matriculado))  # <class 'bool'>

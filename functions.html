Funções em Python

Funções são blocos de código reutilizáveis que realizam uma tarefa específica. Elas ajudam a organizar o programa, evitar repetição e tornar o código mais modular e fácil de manter.

code

Definição (def)

Usamos a palavra-chave def seguida pelo nome da função e parênteses para declarar novos comportamentos.

input

Parâmetros

São valores que a função pode receber como entrada para processar. Eles agem como variáveis locais dentro do escopo.

output

Retorno (return)

Define como a função envia um resultado de volta para quem a chamou, permitindo que o dado seja armazenado em variáveis.

Exemplo Prático

python 
# Definindo uma função simples
def saudar(nome):
    return f"Olá, {nome}! Bem-vindo ao PyChristus."

# Chamando a função
mensagem = saudar("Estudante")
print(mensagem)
error

Esquecer o Parêntese ou Indentação

Um erro muito comum é esquecer os parênteses na definição ou chamada da função, ou não indentar corretamente o bloco de código dentro da função. Em Python, a indentação é o que define o corpo da função.

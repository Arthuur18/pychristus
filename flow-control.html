Controle de Fluxo em Python

A tomada de decisão é o coração de qualquer programa. No Python, usamos estruturas de controle de fluxo para direcionar a execução do código com base em condições lógicas. Através de if, elif e else, podemos criar sistemas inteligentes que respondem a diferentes entradas de dados.

if alt_route

A condição básica. Se a expressão for verdadeira, o bloco de código indentado será executado.

elif add_road

Abreviação de "else if". Permite verificar múltiplas condições em sequência caso a anterior falhe.

else subdirectory_arrow_right

A rota de fuga. Executa o código se nenhuma das condições anteriores for atendida.

terminal Exemplo Prático 

# Verificação de Nota de Estudante
nota = 85

if nota >= 90:
    print("Conceito: A - Excelente!")
elif nota >= 70:
    print("Conceito: B - Aprovado")
elif nota >= 50:
    print("Conceito: C - Recuperação")
else:
    print("Conceito: D - Reprovado")

# Outro exemplo: Verificação de Idade
idade = 18
if idade >= 18:
    pode_dirigir = True
    print("Acesso autorizado")
else:
    pode_dirigir = False
    print("Acesso negado")

Operadores em Python

Operadores são símbolos especiais em Python que realizam operações em variáveis e valores. Eles são os blocos de construção fundamentais para manipular dados, realizar cálculos matemáticos e construir lógica de decisão em seus programas.

functions Aritméticos

  • Adição + 5 + 2 = 7
  • Multiplicação * 5 * 2 = 10
  • Exponenciação ** 5 ** 2 = 25
  • Divisão Inteira // 5 // 2 = 2

compare_arrows Comparação

  • Igualdade == True/False
  • Diferente != a != b
  • Maior que > 10 > 5
  • Menor ou igual <= x <= y

alt_route Lógicos

and

Verdadeiro se ambos forem True.

or

Verdadeiro se um for True.

not

Inverte o valor lógico.

Exemplo Prático

Main.py 
# Cálculo de Área e Verificação de Acesso
raio = 5
pi = 3.14159
area = pi * (raio ** 2)

print(f"A área do círculo é: {area}")

# Lógica de Permissão
idade = 20
tem_ticket = True
pode_entrar = (idade >= 18) and tem_ticket

if pode_entrar:
    print("Acesso concedido ao evento!")
else:
    print("Acesso negado.")
warning

ERRO COMUM: Tipagem Incompatível

Você não pode usar operadores aritméticos entre int e str diretamente.

# Isso causará um TypeError:
print(10 + "20")

Estruturas de Dados em Python

No Python, as estruturas de dados fundamentais nos permitem organizar, gerenciar e armazenar coleções de informações de maneira eficiente. Entender quando usar cada uma é essencial para construir algoritmos performáticos.

format_list_numbered

Listas (List)

Sequências de elementos ordenados e mutáveis. Permitem itens duplicados e são definidas pelo uso de colchetes [].

Ordenado Mutável
key

Dicionários (Dict)

Coleções de pares chave-valor. São não-ordenados por padrão (em termos de indexação numérica) mas altamente eficientes para busca por chaves. Definidos por chaves {}.

Mapeado Eficiente

Exemplo Prático

python
# Criando uma lista de frutas
frutas = ["maçã", "banana", "cereja"]

# Criando um dicionário de uma pessoa
pessoa = {
    "nome": "João",
    "idade": 25,
    "cidade": "São Paulo"
}

# Acessando dados
print(frutas[0])     # Saída: maçã
print(pessoa["nome"]) # Saída: João
error

Erro Comum: IndexError

O erro IndexError ocorre quando você tenta acessar uma posição da lista que não existe (por exemplo, frutas[5] quando a lista só tem 3 itens). Lembre-se: em Python, a contagem começa no zero.

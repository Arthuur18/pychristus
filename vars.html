Variáveis em Python

Imagine as variáveis como etiquetas presas a caixas de memória. Em Python, uma variável é criada no momento em que você atribui um valor a ela pela primeira vez. Não é necessário declarar o tipo explicitamente; o Python é inteligente o suficiente para entender o que você está guardando.

python
1
nome = 'Maria' # Criando uma variável de texto
2
idade = 18 # Criando uma variável numérica

Entendendo o Código

1

Na primeira linha, definimos nome. Como o valor está entre aspas, o Python entende que é uma String (texto).

2

Na segunda linha, definimos idade. Como o valor é um número puro, o Python o classifica como um Integer (inteiro).

warning

Erro comum

Não comece nomes de variáveis com números (ex: 1usuario). Use letras, números ou sublinhados, mas sempre inicie com uma letra ou _.

exercise

Exercício Prático

Crie um programa que solicite o nome do usuário e exiba uma mensagem de boas-vindas personalizada. Use a função input() para receber o dado e o print() para mostrar o resultado.

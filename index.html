O que é Python?

Python é uma linguagem de programação de alto nível, interpretada, de propósito geral e extremamente versátil. Criada por Guido van Rossum e lançada pela primeira vez em 1991, sua filosofia de design enfatiza a legibilidade do código com o uso de indentação significativa.

A beleza do Python reside em ser simples o suficiente para quem está começando, mas poderosa o suficiente para alimentar sistemas de inteligência artificial da NASA, servidores do Instagram e processamento de dados do Google.

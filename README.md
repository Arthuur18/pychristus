# PyChristus

PyChristus é uma plataforma educativa em português para aprender Python de forma prática e visual. O projeto reúne explicações teóricas, exemplos de código, dicas importantes e exercícios para auxiliar iniciantes no aprendizado da linguagem.

## Objetivo

O objetivo principal do projeto é facilitar o ensino de Python com uma abordagem didática, organizada por tópicos e acessível para quem está começando na programação.

## Conteúdo abordado

A aplicação inclui módulos sobre:

- Introdução ao Python
- Fundamentos da linguagem
- Variáveis
- Tipos de dados
- Operadores
- Estruturas de controle
- Loops
- Estruturas de dados
- Funções
- Exercícios práticos

## Como executar localmente

Primeiro, instale as dependências:

```bash
npm install
```

Em seguida, inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Após isso, abra o endereço informado no terminal no navegador, normalmente:

```text
http://localhost:5173/
```

## Como gerar build de produção

```bash
npm run build
```

Para visualizar o build gerado localmente:

```bash
npm run preview
```

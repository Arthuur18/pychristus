Estruturas de Repetição em Python

Loops (laços de repetição) são ferramentas fundamentais que permitem executar um bloco de código repetidamente enquanto uma condição for atendida ou para cada item em uma coleção. Eles automatizam tarefas repetitivas, garantindo eficiência e redução de redundância no seu código.

repeat

O Loop 'for'

O comando for é utilizado para iterar sobre uma sequência (seja uma lista, uma tupla, um dicionário, um conjunto ou uma string). É ideal quando você sabe exatamente quantas vezes deseja repetir a ação ou quando deseja processar cada elemento de uma coleção.

update

O Loop 'while'

O comando while executa um bloco de código repetidamente desde que uma condição booleana específica permaneça verdadeira. É comumente usado quando o número de repetições não é conhecido antecipadamente.

terminal Exemplo Prático

# Exemplo de loop 'for' nomes = ["Ana", "Bruno", "Clara"] for nome in nomes: print(f"Olá, {nome}!") # Exemplo de loop 'while' contador contador = 0 while contador < 3: print(f"Contagem: {contador}") contador += 1
warning

Erro Comum: Loop Infinito

Um dos erros mais críticos ao usar while é esquecer de atualizar a variável de controle. Se a condição nunca se tornar falsa, o programa entrará em um loop infinito, consumindo todos os recursos do processador e travando o sistema. Sempre verifique se o estado da condição muda dentro do bloco!
